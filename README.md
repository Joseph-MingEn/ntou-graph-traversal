# 圖的走訪 DFS／BFS

互動式繁體中文教學頁，逐步展示無向圖的深度優先搜尋（DFS）與廣度優先搜尋（BFS）。

## 範例圖

頂點：A、B、C、D、E、F

無向邊：(A,B)、(A,C)、(B,C)、(B,D)、(C,D)、(C,E)、(D,F)、(E,F)、(D,E)。

鄰接點依英文字母順序檢查。每按一次「單步執行」，只會拜訪／取出一個節點、檢查一條相鄰邊，或執行一次 DFS 回溯。

- DFS 用遞迴堆疊深入探索，已發現的鄰點會略過。
- BFS 用先進先出佇列；在無權圖中，首次發現節點時確定其最少邊數距離。
- DFS 走訪邊以虛線顯示；BFS 最短路徑樹以實線顯示。
