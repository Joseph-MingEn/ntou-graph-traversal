04 / CONCEPTS

原理與正確性

DFS 與 BFS 都會系統性地探索可達頂點，差別在於下一個待處理頂點的選擇方式。

01 / DFS

深度優先搜尋

使用遞迴呼叫堆疊實作。依鄰接串列順序檢查鄰點；遇到未拜訪頂點，就立即深入該頂點。沒有未拜訪鄰點時，函式返回上一層繼續檢查，所以呼叫路徑正好呈現目前的深入路線。

時間 O(|V| + |E|)　空間 O(|V|)
02 / BFS

廣度優先搜尋

使用先進先出佇列（Queue）。先處理起點所有鄰點，再處理距離更遠的頂點。對無權圖，BFS 首次到達每個頂點時，得到從起點出發的最少邊數距離。

時間 O(|V| + |E|)　空間 O(|V|)
03 / ORDER

自己推導走訪順序

邊集合只定義哪些頂點相連，沒有指定鄰點順序。本頁採字母順序。先查看目前的堆疊或佇列，再依照每一步實際檢查的鄰邊推導；完整走訪序列不會預先揭露。

起點可自行切換
04 / COVERAGE

走訪範圍

走訪從指定起點出發，只會涵蓋與起點連通的頂點。這題的圖是連通圖，所以從任一頂點出發，DFS 與 BFS 都會恰好拜訪全部六個頂點各一次。

標記 visited，避免重複拜訪
本展示採用的不變條件每個頂點一旦開始拜訪（DFS）或加入佇列（BFS）就立即標記為已發現；因此每個頂點只會遞迴進入一次或入佇列一次。DFS 的呼叫堆疊路徑與 BFS 的佇列，分別記錄目前的深入路線與待處理頂點。
